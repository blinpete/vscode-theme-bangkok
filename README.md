## Match with System

<!--eslint-skip-->

```jsonc
// .vscode/setting.json
{
  "window.autoDetectColorScheme": true,
  "workbench.preferredLightColorTheme": "Bangkok Light",
  "workbench.preferredDarkColorTheme": "Bangkok Dark",
}
```
